# ADR-0001: Декомпозиция по бизнес-доменам

- Статус: принято
- Дата: 2026-10-02

## Контекст

Маркетплейс объединяет каталог, персональную ленту, пользователей, заказы,
платежи и уведомления. Эти части имеют разные модели данных, риски и профили
нагрузки. Особенно важна изоляция платёжных данных от каталога и возможность
масштабировать чтение ленты независимо от оформления заказа.

## Решение

Выделить шесть сервисных границ: Identity, Catalog, Feed, Order, Payment и
Notification. API Gateway (Nginx) является входной технической границей, а Event
Broker — инфраструктурным контейнером, но не владельцем доменных данных.

Каждый сервис владеет своим хранилищем; доступ к чужим таблицам запрещён.
Для внутренних вызовов выбран HTTP/JSON, для событий — RabbitMQ (AMQP),
для транзакционных данных — PostgreSQL, для Feed — OpenSearch и Redis.
Синхронные вызовы используются, когда вызывающей стороне нужен немедленный
ответ. События используются для распространения уже свершившихся изменений.

## Последствия

Плюсы: независимое масштабирование, явное владение данными, изоляция платежей,
слабая связанность подписчиков. Минусы: распределённые транзакции, eventual
consistency, необходимость наблюдаемости и идемпотентных обработчиков.
