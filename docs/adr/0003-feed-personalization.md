# ADR-0003: Гибридная персонализация ленты

- Статус: принято
- Дата: 2026-10-02

## Контекст

Персональная лента имеет высокий объём чтения и допускает небольшую задержку
обновления. Новому пользователю или товару недостаточно истории для сложной
ML-модели (cold start).

## Решение

Feed Service строит кандидатов из поискового индекса и ранжирует их по смеси:
доступность и базовая популярность, совпадение категорий/ценовых предпочтений и
поведенческие сигналы (просмотры, добавления в корзину, покупки). Для cold start
используются популярные доступные товары с разнообразием категорий. Профиль
интересов пересчитывается асинхронно, а готовая страница кратковременно кешируется.

Сервис хранит производные признаки и индекс, но не становится владельцем
профилей, товаров или заказов. Товары, корзины и покупки поступают событиями
владельцев. Просмотры принимает сам Feed через API Gateway. OpenSearch хранит
проекцию каталога, Redis — признаки интересов и кеш, включая общую fallback-ленту.

## Последствия

Подход даёт полезную персонализацию без обязательной online-ML-инфраструктуры и
деградирует до неперсональной выдачи. Индекс и признаки eventual consistent;
фильтрация и короткий TTL снижают устаревание, но не гарантируют наличие товара.
Гарантию обеспечивает атомарный резерв Catalog при checkout. При недоступности
обоих хранилищ Feed возвращает 503. Индекс восстанавливается из snapshot API
Catalog с последующим применением событий по версии товара; потеря признаков
допустима и переводит персонализацию в cold start.
